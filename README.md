# Indian Traffic Sign Classification

## About
A deep learning project that classifies Indian traffic signs from images using a trained TensorFlow/Keras model.

## Technologies
- Python
- TensorFlow and Keras
- Streamlit
- NumPy
- Pillow

## Features
- Upload a traffic sign image.
- Predict its traffic sign category using a trained model.
- View the prediction through a Streamlit interface.

## Project Files
- `app.py` - Application code
- `requirements.txt` - Python dependencies
- `traffic_sign_classification_final.keras` - Trained model

## Run the Project
1. Install dependencies:
   `pip install -r requirements.txt`

2. Start the application:
   `streamlit run app.py`
